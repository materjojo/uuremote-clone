# UU远程 macOS 4.48.1 逆向分析（四）：UI 结构

> 依据：Swift 类型描述符（3526 类型）、内嵌源码路径（261 文件 / 33 模块）、
> `Localizable.strings`（1976 条文案，zh-Hans/en 双语）、`Assets.car`、Lottie 资源。

---

## 1. 窗口体系

| 窗口 | 类 | 说明 |
|---|---|---|
| 主窗口 | `StartWindowController` / `SpiltHome` | 左侧设备/功能导航 + 右侧内容 |
| 登录 | `Login/*`（手机号、邮箱、二维码、区域选择、验证码） | 独立窗口 |
| 远控窗口 | `ControlDevice/*` | 无边框可缩放，含悬浮工具条 |
| 设置 | `AppSettingWindowController` | 常规/安全两类 |
| 关于 | `AboutAppWindowController` | — |
| 设备详情 | `ControlledDetail` | 被控设备信息/权限 |
| 文件传输 | `FileTransfer` | 双栏队列 |
| 终端 | `Terminal`（SwiftTerm） | tmux 会话列表/终端 |
| 引导 | `AppPermissionNoticeWindow`、`DeviceGuide` | 权限申请、使用引导 |
| 悬浮球 | `FloatingBall` | 被控时悬浮状态 |

## 2. 主界面（Home）

从文案键还原的信息架构：

```
Home.Device.*            设备卡片：在线/离线、重命名、重启、关机、删除
Home.Device.Restart.Device.Dialog.*
Home.Device.PowerOff.Device.Dialog.*
Setting.Menu.*           设置菜单：安全锁定/上传日志/关于/反馈/客服/FAQ/下载移动端/远程协助/设备管理/退出登录
NowDevice.*              当前正在被控制的设备列表
DeviceList / SwitchDevice 设备切换
MessageCenter            消息中心
CloudDisk / CloudPc      云设备（移除）
```

设备卡片字段（Codable 键）：`device_name`、`device_id`、`platform`、`version_name`、`support_wol`、
`controlled_support`、`device_preferences`、`online`、`tags`。

## 3. 远控窗口（ControlDevice）

### 3.1 顶部/悬浮工具条
```
Control.Menu.switchScreen        显示屏（多屏切换，快捷键提示）
Control.Menu.fullScreen          全屏 / 缩小
Control.Menu.windowSetting       窗口设置：不透明度、小窗模式、帧率上限、分辨率
Control.Menu.quality             画质（流畅/均衡/高清/蓝光/自动/自定义）
Control.Menu.mouse               鼠标模式：智能鼠标 / 被控端鼠标 / 主控端鼠标
Control.Menu.keyboard            键盘：优先响应控制端快捷键、使用 macOS 快捷键
Control.Menu.playVoice           播放被控端声音
Control.Menu.netInfo             常驻显示网络状态
Control.Menu.mutiScreen          多显示屏管理
Control.Menu.zoom                窗口缩放
```

### 3.2 右侧/底部面板
- 文件传输（拖拽、粘贴文件 `PasteFile`）
- 剪贴板同步（文本/图片/文件）
- 标注（`GvPb_Draw*`）
- 端口映射（`PortMapping`）
- 终端（`Terminal`）
- 快捷键映射（`/api/v1/tool/keymapping/list`）

### 3.3 状态覆盖层
- 连接中：`ProbingWaitingMessageType` + Lottie 动画
- 弱网提示：`abnormal_*` 归因 → 文案
- 解锁：`UnlockProgressBar`
- 静默升级：`SilentUpgradeLoading`

## 4. 设置页

```
Setting.Category.regualr     常规（原文拼写 regualr）
Setting.Category.security    安全
Setting.AutoStart            开机自启动
Setting.virtualDisplay       自动创建虚拟屏
Setting.ClosingWindow        关闭窗口时（隐藏到菜单栏 / 退出）
Setting.FileTransfer.ReceiveDirectory  移动设备传输文件存储路径
Setting.Controlled.allowed   允许同账号控制本设备
Setting.Controlled.System.permission   系统权限配置
Setting.Authentication       实名认证（姓名/身份证）
```

## 5. 视觉资源

- 字体：`Barlow-SemiBold.ttf`（数字/标题），系统中文字体
- 图标：`Assets.car`（约 30 MB 资源包内含全部图标/插画）
- 动画：`cloud_queue_waiting_animation.json`（Lottie）、`cloud-device-skeleton.webp`、`payment-bg-skeleton.webp`
- 主题：深色为主，远控窗口全黑背景；强调色为品牌绿（UU 系列）

## 6. 文案抽取

`zh-Hans.lproj/Localizable.strings` 1976 行，键名按模块前缀组织，可直接生成
`Localizable.xcstrings`。复刻工程已内置精简版（覆盖主流程）。

## 7. 复刻范围

保留：登录占位、设备列表、设备卡片操作、远控窗口与工具条、设置、文件传输、终端入口、关于。
移除：CloudPc / CloudDisk 全部入口与 `LaunchCloudPcApp` 消息分支、云设备市场、云盘、实名认证中的云游戏条款。
